# 📚 Book Management System

A RESTful Book Management System built with **NestJS 11** that demonstrates production-ready backend development practices, including authentication-ready architecture, request logging, global exception handling, validation, reusable utilities, and a scalable project structure.

## ✨ Features

- 📖 Book CRUD Operations
- 🔄 Book Availability Status Management
- 🗑️ Soft Delete & Restore
- 🔍 Search & Filter Books
- 📄 Pagination & Sorting
- ✅ DTO Validation
- 📊 Database Statistics
- 📑 Swagger API Documentation
- 📝 Global API Request Logging
- 🌐 Request Audit — IP, Browser, OS & Device
- ⚡ Global Exception Handling
- 🎯 Common API Response Structure
- 🛠️ Reusable Helpers, Decorators & Interceptors
- 🗄️ TypeORM Integration
- 🚀 Production-Ready Folder Structure

## 🛠️ Tech Stack

- **NestJS 11**
- **TypeScript**
- **TypeORM**
- **MySQL**
- **Swagger**
- **EJS**
- **Class Validator**
- **Express**

## 🎯 Purpose

This project is designed as a learning and reference repository for building **scalable, maintainable, and production-grade NestJS backend applications** using modern development practices and architectural patterns.
