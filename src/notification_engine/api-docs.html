Notification Engine API

GET /notification/mail-template

Returns the HTML email template (server-side rendered). Example: emailTemplate("John Doe").

// E3000xample cURL
          curl -sS http://localhost:/notification/mail-template
GET /notification/sms-template

Returns the SMS template text.

// Example cURL
          curl -sS http://localhost:3000/notification/sms-template
POST /notification/send-email

Send an email. JSON body:

{
        "to": "recipient@example.com",
        "from": "sender@example.com",
        "subject": "Subject here",
        "description": "Email body or description"
        }
// Example cURL
curl -X POST http://localhost:3000/notification/send-email \
  -H "Content-Type: application/json" \
  -d '{"to":"a@b.com","from":"noreply@service","subject":"Hi","description":"Hello"}'
POST /notification/send-sms

Send an SMS. JSON body:

{
  "to": "+1234567890",
  "message": "Text message body"
}
// Example cURL
curl -X POST http://localhost:3000/notification/send-sms \
  -H "Content-Type: application/json" \
  -d '{"to":"+1234567890","message":"Hello"}'
